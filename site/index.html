WingetDeck

Upgrade your Windows apps. Stop when you need to.

Tick the apps, press Upgrade, and watch each one download and install. It runs winget for you in a window you can click. One exe, with no installer and no admin rights.

The Pause button tells you what it will really do

Stopping an upgrade safely depends on what winget is doing at that moment. The buttons change to match. Choose a moment to see them.

PauseStop after this oneStop now

Pause holds the download right away, and Resume carries on. In a test, the network fell from 47 MB/s to zero within a second.

Pause after this packageStop after this oneStop now

A Windows service does this download and keeps going even if winget is stopped, so a true pause is not possible. WingetDeck says so, and offers to change the one winget setting that makes it possible. It backs up your settings first, and you can undo it.

An installer is never frozen, because that could leave an app half-installed. Force stop is there for an installer that has hung, and it asks you twice.

ResumeStop

After a pause takes effect, nothing is running. Resume starts the next package, and Stop ends the run. If the app closes at any point, it offers to continue the queue next time.

What it does to your PC

  • It upgrades only what you tick.
  • It keeps its data in a WingetDeck-data folder beside the exe. If that folder cannot be written to, or you run it as administrator, it uses %LOCALAPPDATA%\WingetDeck and tells you so.
  • It saves a list of your installed versions before each run, so there is a record of how things were.
  • It has no network code of its own. All downloads are winget's.
  • Its logs stay on your PC. A diagnostic report removes your user name and the secrets it recognises, and shows what it includes before saving. Read it before you share it.

Get started

  1. Download WingetDeck-x64.exe and put it in any folder. You need Windows 10 version 1809 or newer, and winget 1.4 or newer.
  2. Open it. The exe is not signed, so Windows may warn that the publisher is unknown. If you trust this page, choose More info, then Run anyway. You can compare the file with the checksums on the release page first.
  3. Choose a source, press START, tick your apps, and press UPGRADE.

The 32-bit version works the same way, but shows an animation and the elapsed time instead of a live percentage.
